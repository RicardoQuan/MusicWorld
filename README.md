# 歌词桥

同一份 APK 分别安装在播放网易云音乐的手机和车机/接收端手机。手机读取网易云音乐的媒体会话；用户导入的本地 LRC 优先使用，否则优先查询网易云，未登录或未匹配时再尝试 LRCLIB。命中的歌词通过蓝牙经典 RFCOMM 发送；车机端显示透明的三行歌词悬浮层。网易云返回 YRC 逐字歌词时，字符会按播放进度逐渐变色；只有句级 LRC 时则按句显示。最低 Android 9（API 28），按当前屏幕尺寸自适配。

## 获取 APK

GitHub 仓库保存源码，不包含本地调试 APK。构建方法见“从源码构建”；调试版 APK 由 Gradle 输出到 `app/build/outputs/apk/debug/app-debug.apk`，可手动安装，不用于 Play 商店发布。将同一 APK 安装到手机和车机，系统提示时允许此来源安装应用。

## 首次设置

### 手机发送端

1. 首次打开应用时选择“手机发送端”进入手机配置；保存角色后，下次打开会直接进入该配置页。
2. 点击“登录网易云账号”，默认显示二维码。用另一台已登录网易云的设备扫描并在官方 App 确认；也可点“网页登录（当前设备）”，在应用内打开 `music.163.com` 登录，或点“密码 / 短信登录”。网易云音乐 App 和外部浏览器的登录状态不会自动共享给本软件。网页登录完成后应用会检测网易云会话并在本机加密保存；需要退出时点“退出网易云账号”。网页登录若被站点限制，可返回二维码或尝试现有登录方式。
3. 播放歌曲时，可点“导入当前歌曲的本地 LRC”选择一个可访问的带时间戳 `.lrc` 文件。导入后会绑定到当前歌曲并在后续播放时优先使用。应用不会扫描或读取网易云私有缓存目录。
4. 在系统设置中允许“歌词桥”读取通知使用权。Android 通过媒体会话读取当前歌曲、歌手和进度，不读取屏幕或录音。
5. 在系统蓝牙设置里与车机或接收端手机完成配对。Android 12 及以上还需授予“附近的设备”；Android 13 及以上需允许通知。
6. 完成授权和配对后，打开“手机发送端”会自动启动蓝牙发送服务。手机会显示持续通知，可从应用或通知停止发送；下次进入发送端页面会再次自动启动。

歌词按用户导入的本地 LRC、网易云、LRCLIB 的顺序查找。本地导入仅接受含时间戳且可解析的歌词文件，并按歌曲名和歌手绑定；手机发送页会标明实际命中的来源。应用只读取用户通过系统文件选择器明确选中的文件，不扫描网易云私有缓存。若出现 8821 行为验证或其他安全校验，扫码和网页登录也可能受限；应用不会绕过校验。密码和短信验证码登录也可能被网易云风控拒绝。网易云登录和歌词接口不是网易云面向第三方公开承诺的 API，可能因账号限制或服务端变更而失效。使用 LRCLIB 时，歌曲名、歌手、专辑和时长会发送给该服务查询；网易云会话 Cookie 不会发送给 LRCLIB。不要把账号密码或短信验证码发送到聊天或其他渠道。

### 车机或接收端手机

1. 首次打开应用时选择“车机显示端”，并在系统蓝牙设置里与发送手机完成配对；保存角色后，下次打开会直接进入车机显示设置。切换到显示端时会关闭本机的手机发送服务；切换到发送端时会停止车机接收服务并隐藏歌词。
2. 在“车机显示设置”中选择发送手机一次；应用会记住所选设备。以后进入车机显示设置时会自动开启蓝牙并连接该手机。Android 12 及以上由系统弹窗确认开启蓝牙，并按提示授予蓝牙和通知权限。
3. 点“开启悬浮窗权限”，在系统设置中允许“显示在其他应用上层”。蓝牙数据连接成功后自动显示歌词；也可在设置页点“连接并显示歌词”重新连接。
4. 字号、文字透明度、滚动时长，以及已唱和未唱的颜色都可在车机设置页调整。收到 YRC 时当前歌词逐字填色；只有 LRC 时按整句显示。悬浮层左上角显示歌曲名和歌手，没有底板或边框。
5. 设备角色会记住上次选择；“车机开机自动连接”默认开启。保存手机后，显示端开机时自动连接该手机并持续重试。蓝牙数据连接成功后自动显示悬浮歌词，收到歌词时更新内容。歌曲名和歌手固定在歌词上方，歌词切换时单独渐隐并上移。该开关只控制车机，不会自动启动手机发送端。长按歌词区域可拖动整组歌词与歌曲信息，位置会记住；隐藏悬浮层可在设置页点“隐藏歌词”。

Android 9 不需要“附近的设备”运行时授权；蓝牙配对仍须先在系统设置中完成。车机固件可能限制第三方悬浮层或过滤开机广播，最终效果以 UNI-V 实车为准。

## 两台手机蓝牙软件测试

同一 APK 安装在两台 Android 手机上即可验证软件链路：

1. 两台手机先在系统蓝牙设置中互相配对。
2. 发送手机选择“手机发送端”，开启通知使用权；如需网易云优先查询，完成网易云扫码或其他登录。打开网易云播放歌曲并开始蓝牙发送。
3. 接收手机选择“车机显示端”，进入车机设置选择发送手机，授予悬浮窗权限后点“连接并显示歌词”。
4. 验证歌曲切换、暂停/继续、进度更新、隐藏/再显示和蓝牙断开后的自动重连；发送端应显示实际命中的歌词来源。退出网易云后仍可尝试 LRCLIB。
5. 调整字号、文字透明度和滚动时长。短按或长按后不拖动歌词会出现隐藏选项；长按并移动可拖动歌词且记住位置。设置页可复位到屏幕中央。设备选择收在一个配对设备列表中。接收端可关闭并重新开启“车机开机自动连接”检查开关状态。

测试报告注明手机型号、Android 版本、登录状态、曲名和歌词匹配情况。实车还需确认 A2DP 音频与 RFCOMM 并行，以及 UNI-V 原厂桌面对悬浮层和开机启动的处理。

## 歌词来源与隐私

- 网易云登录和取词请求从手机直接通过 HTTPS 发往网易云域名；网页登录在应用内 WebView 完成，应用只读取网易云 HTTPS 域名的 `MUSIC_U` 会话 Cookie 并交给现有加密会话存储。系统浏览器 Cookie 不会被读取；用户名和密码不会发往第三方歌词服务或车机。
- 网易云无有效时间戳歌词时，应用会通过 HTTPS 向 LRCLIB 查询。该请求包含歌曲名、歌手、专辑和时长；LRCLIB 不会收到网易云 Cookie 或账号凭据。
- 密码只用于登录请求，不写入偏好设置或日志；成功登录后，会话 Cookie 通过 Android Keystore 的 AES/GCM 密钥加密后存入应用私有设置。退出登录会删除加密会话和对应密钥。
- 车机只接收曲目信息、匹配到的带时间戳歌词和播放状态，不接收网易云账号、密码或会话 Cookie。
- 网易云与 LRCLIB 的 API 都可能变化；网易云扫码也可能遇到 8821 或其他安全验证。

## 从源码构建

需要 JDK 17、Android SDK Platform 36、Build Tools 36.0.0 和网络连接。Gradle Wrapper 使用 Gradle 9.6.0。

Windows 工作区路径含中文时，当前 Android Gradle/测试执行器组合需要临时使用未占用的 ASCII 盘符运行单元测试：

```powershell
$env:JAVA_HOME = 'C:\path\to\jdk-17'
$env:ANDROID_HOME = 'C:\path\to\android-sdk'
$env:ANDROID_SDK_ROOT = $env:ANDROID_HOME
subst U: 'D:\codex\02_软件开发'
Set-Location U:\
.\gradlew.bat --no-daemon --no-build-cache --console=plain clean testDebugUnitTest assembleDebug
Set-Location D:\codex\02_软件开发
subst U: /D
```

构建输出位于 `app\build\outputs\apk\debug\app-debug.apk`。分发前使用上述清理构建，避免增量合并残留旧 DEX 导致 `NoSuchMethodError`；仅检查 Java 编译或 APK 签名无法发现这种错误。复制到 `dist\univ-lyrics-bridge-debug.apk` 后即可手动分发。若盘符 `U:` 已被占用，请换一个空闲盘符。

## 停止与卸载

手机端和接收端分别在应用或持续通知中停止服务；随后可在系统应用管理中卸载“歌词桥”。不再使用时，可在系统蓝牙设置中单独取消配对。
