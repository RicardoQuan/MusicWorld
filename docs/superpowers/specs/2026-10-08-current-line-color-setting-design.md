# 当前行颜色设置设计

## 目标

在车机显示设置中新增独立的“当前行颜色”选项。颜色可单独保存，并在已显示的歌词悬浮层中立即生效；已唱上一句和未唱下一句仍可分别调色。

## 当前实现

- `CarModeActivity` 已通过颜色预设弹窗设置上一句和下一句颜色。
- `AppSettings` 分别保存这两个颜色。
- 普通句级歌词的当前行颜色目前固定为金色 `0xFFFFCD53`。
- YRC 逐字歌词通过 `CharacterProgressSpan` 使用已唱字色和未唱字色渐变。

## 已确认的行为

- 车机显示设置增加“当前行”颜色选择项，沿用现有预设颜色弹窗与按钮预览样式。
- 新设置使用独立偏好键；未设置过的设备默认使用现有金色 `0xFFFFCD53`。
- 句级歌词的当前行整句使用用户选择的颜色。
- YRC 逐字歌词中，已经唱到的字使用当前行颜色，未唱字继续使用“未唱（下一句）”颜色，以保留逐字渐变效果。
- “已唱（上一句）”仍只控制上一行；“未唱（下一句）”仍控制下一行及当前行未唱字。
- 选择颜色后立即刷新可见悬浮层，并持久化到下次启动。
- 字体透明度继续统一作用于歌词文字，不新增悬浮层控件或边框。

## 实现范围

1. `AppSettings`：增加当前行颜色的默认值、读取和保存方法。
2. `OverlayColorPalette`：公开当前行默认金色，并让该默认色可以被现有预设选择器识别。
3. `CarModeActivity`：在车机设置卡片增加颜色按钮，选择后更新按钮预览、保存设置并刷新悬浮层。
4. `LyricsOverlayController`：加载当前行颜色，在普通歌词和逐字歌词的已唱字渲染路径中使用该值。
5. `OverlayColorPaletteTest`：覆盖默认当前行颜色及预设可选性；保留现有颜色预设测试。

## 验收

- 新安装或未设置过的设备仍显示金色当前行。
- 更改当前行颜色不会更改上一句或下一句颜色设置。
- 普通句级歌词的当前行显示所选颜色。
- 逐字歌词仍按播放进度逐字填色，已唱字使用当前行颜色，未唱字颜色保持独立设置。
- 退出并重新打开应用后选择仍保留；可见歌词悬浮层在选择后立即更新。

## 边界

本次只增加当前行颜色设置，不加入自定义 RGB/色值输入，不改变歌词来源、播放同步或悬浮层布局。实车观感仍需在 UNI-V 或两台 Android 手机上确认。
