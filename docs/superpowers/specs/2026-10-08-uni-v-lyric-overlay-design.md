# UNI-V 车机歌词悬浮显示设计说明

日期：2026-10-08  
状态：用户确认的界面、开机连接和网易云专用歌词已实现；自动化构建通过，真实设备验证待完成

## 目标

手机使用网易云音乐播放歌曲时，在 2022 款长安 UNI-V 的 Android 9 车机屏幕上显示与播放进度同步的歌词。用户确认车机允许安装第三方 APK，也接受手机端安装配套功能。

## 推荐方案

交付一份可安装在手机和车机上的 APK。首次启动时选择运行角色：

- **手机发送端**：监听 Android 媒体会话，自动匹配带时间戳的歌词，通过蓝牙发送曲目信息、歌词和播放状态。
- **车机显示端**：连接手机并在系统悬浮窗中显示当前歌词。

手机作为经典蓝牙 RFCOMM/SPP 服务端，车机作为客户端。现有 A2DP 连接继续传输音频；歌词数据使用独立的 RFCOMM 通道。Android 提供这两端的 RFCOMM API，但长安车机固件能否同时维持 A2DP 音频和应用级 RFCOMM 连接，需要在实车上确认。

## 组件与数据流

### 手机端媒体监测

- 通过 `NotificationListenerService` 和 `MediaSessionManager` 获取当前活动媒体会话，不读取屏幕画面、不录音。
- 识别网易云音乐会话，读取歌曲名、歌手、时长、播放/暂停状态和播放位置。
- 用户需要在 Android 设置中授予通知使用权。Android 官方说明，启用的通知监听服务可以访问活动媒体会话。[MediaSessionManager](https://developer.android.com/reference/android/media/session/MediaSessionManager)
- 手机端由用户主动启动发送，并以可见通知维持蓝牙连接；车机端可手动连接，也可在保存配对手机并开启设置后于开机时自动重连。Android 8 起后台服务受限，前台服务会显示持续通知。[Android 前台服务说明](https://developer.android.com/develop/background-work/services/fgs)

### 歌词匹配

- 用歌名、歌手和时长查询自动歌词匹配模块，解析带时间戳的 LRC 歌词。
- 歌词来源封装为可替换的 `LyricProvider`。用户暂不指定来源；实现阶段选择一个可用来源接入，避免把第三方 API 地址写死在媒体监测、蓝牙或界面代码中。
- 手机缓存已匹配歌词。没有匹配结果、来源不可达或返回内容没有时间戳时，界面明确提示并提供重试，不伪造同步状态。
- 网易云官方第三方歌词 API 尚未确认；公开资料中可见社区实现使用多个歌词来源，但可用性和授权情况不能据此保证。[社区实现参考](https://github.com/tcrrry/desktop-lyrics)

### 蓝牙传输

- 手机端打开固定 UUID 的 RFCOMM 服务；车机端从已配对设备中选择手机并发起连接。
- 消息采用带版本号的长度前缀 UTF-8 JSON 帧，至少支持握手、曲目变化、LRC、播放状态/进度和连接状态消息。
- 曲目变化时发送曲目信息和完整 LRC；播放过程中发送进度、状态和采样时间。车机依据进度和时间戳本地更新歌词，降低短暂传输延迟的影响。
- 手机与车机的 `elapsedRealtime` 起点不同。手机发送前先把媒体会话位置投影到发送时刻；车机收包后将位置重新锚定到本机单调时钟，不能直接跨设备比较两个时间戳。
- 连接失败时显示原因并允许重连。蓝牙连接操作在后台线程执行；Android 官方文档要求服务端和客户端使用同一 UUID，并避免在 UI 线程执行阻塞连接调用。[Bluetooth RFCOMM 连接指南](https://developer.android.com/develop/connectivity/bluetooth/connect-bluetooth-devices)

### 车机显示

- 车机端通过 Android `TYPE_APPLICATION_OVERLAY` 显示无底板、触屏穿透的歌词层。
- 车机设置页自适应横屏与窄屏，提供字号、文字透明度和隐藏操作；歌词窗口自身不放控制按钮。
- 需要用户授予“显示在其他应用上层”权限；Android 官方将此类悬浮窗定义为应用窗口层级上的 overlay。[WindowManager.LayoutParams](https://developer.android.com/reference/android/view/WindowManager.LayoutParams)
- 车机端显示手机连接状态、当前曲目和歌词匹配状态。失去连接时提示重连；歌词未匹配时不显示旧曲歌词。

## 首次使用流程

1. 将同一 APK 安装到手机和车机，并分别选择对应角色。
2. 在车机系统蓝牙设置中与手机完成配对；手机原有蓝牙音频播放方式保持不变。
3. 手机端开启通知使用权，并启动发送服务。
4. 车机端授予悬浮窗权限，选择已配对手机并连接。
5. 手机在网易云音乐播放歌曲后，车机端显示匹配到的同步歌词。

## 错误处理与隐私

- 无活动媒体会话：提示开启通知使用权或确认网易云正在播放。
- 歌曲信息不足/歌词无匹配：显示曲名和“未匹配到歌词”，提供重试。
- 蓝牙中断：显示断开状态并支持重新连接；不继续显示上一首歌的歌词。
- 首版设计允许未登录时查询 LRCLIB；该来源策略已被用户后续要求覆盖。当前只有网易云可作为歌词来源，网易云登录只在手机端直接使用 HTTPS；密码不落盘，登录会话加密保存在手机。手机与车机之间仅发送媒体信息、网易云歌词数据和播放状态。

## 兼容性

- 最低支持 Android 9（API 28），满足车机要求；同一 APK 用于手机发送端。
- 手机读取媒体会话需要通知使用权；车机显示悬浮歌词需要 `SYSTEM_ALERT_WINDOW` 用户授权。蓝牙运行时权限按手机/车机的 Android 版本处理。
- 用户开始发送/显示时会看到持续通知，可从应用或通知停止服务。
- 车机分辨率、横竖屏策略、悬浮层是否被原厂桌面遮挡，以及蓝牙 A2DP/RFCOMM 并行行为，需要实车验证。

## 验收标准

- 同一 APK 可以在手机端和 Android 9 车机端分别进入正确角色。
- 手机端能检测网易云活动媒体会话，并在曲目切换、暂停和播放进度变化时更新状态。
- 成功匹配的带时间戳歌词通过 RFCOMM 到达车机，并跟随播放位置逐句更新。
- 车机悬浮窗按播放进度滚动显示三行歌词，设置页可调整字号/文字透明度并隐藏；断连、权限未授予或歌词未匹配时有明确提示。
- 手机端蓝牙服务运行期间显示持续通知，并提供停止入口。
- 实车确认蓝牙数据通道和音频能并行工作；若车机固件不支持，启用 Wi-Fi 作为备选传输通道。

## 尚待实现阶段确定的内容

- UNI-V 实际显示区域已确认 1280×720；设备密度、遮挡区域和最佳安装后视觉位置仍需实车检查。
- 两手机蓝牙验收和 UNI-V 实车验证结果。

首版实现选择：手机端有网易云加密会话时优先请求网易云同步歌词；未登录、未匹配或私有接口失败时回退到 LRCLIB。该首版记录已被用户在 2026-10-08 的后续要求覆盖：歌词来源现在只允许网易云，不能登录或网易云未收录时显示未匹配状态，不再查询 LRCLIB。网易云 YRC 逐字数据优先用于逐字颜色进度；网易云只返回 LRC 时保留句级同步显示。

## 用户确认的界面与自动连接更新（2026-10-08）

以下更新由用户在界面预览中确认，覆盖上文中与其冲突的首版交互描述；原有一 APK 双角色、手机读取网易云媒体会话、RFCOMM 传输和 Android 9 最低版本继续保留。

### 车机设置页与适配

- UNI-V 车机实际屏幕为 **1280×720、16:9 横屏**。界面依据可用 dp 宽度和方向自适配，不用固定像素布局；宽屏并列展示设备、连接、字号与歌词文字透明度设置，较窄屏可纵向滚动。
- 车机显示端使用一页完成日常设置。当前页面只显示已记住的设备；通过选择器弹窗查看和切换已配对设备，所选设备持久保存；再次打开和车机重启后不要求重新选择。
- 字号和歌词文字透明度只在应用设置页调整。歌词悬浮层不显示按钮、状态栏、边框或底板，不接收触摸；字号和文字透明度作用于歌词文字，默认字号 28 sp、默认文字透明度 90%。
- 歌词为三行滚动视图：上一句用较暗颜色、当前句用金色高亮、下一句用白色；播放进度跨过时间戳时三行向前滚动。无可用歌词时悬浮层不保留旧歌内容。
- 图标采用用户选择的 **C「车道歌词」**方向：简洁道路/车道线与歌词线组合，使用适配器图标资源，保持小尺寸下清晰。

### 车机开机连接

- “开机自动连接”设置只控制车机接收端，不自动启动手机发送端。开启后车机在 `BOOT_COMPLETED` 时读取保存的蓝牙设备地址并启动接收服务，持续按退避间隔重连；用户关闭该设置后开机不启动连接。
- 若用户已授予悬浮窗权限，车机接收端重连成功并收到可显示的时间戳歌词后自动显示歌词层；未授权或未保存设备时不弹出 Activity、不崩溃，并通过应用状态页说明需要完成的操作。
- 该服务沿用 `connectedDevice` 前台服务类型和持续通知。Android 15 对从开机接收器启动的部分前台服务类型有限制；`connectedDevice` 不在禁止类型列表中。以 UNI-V Android 9 为目标实测，并保留高版本权限和服务启动失败的可见状态。[Android 开机启动限制](https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start)

### 歌词匹配修正

- 手机发送端提供网易云账号登录入口。用户在手机端输入手机号/邮箱和密码，或使用短信验证码，应用直接通过 HTTPS 连接网易云服务；密码只在登录请求期间保留在内存中，不写入日志或本地偏好。登录成功后只在手机上保存加密后的会话 Cookie，退出登录时删除。车机接收端不保存网易云凭据，应用不把账号或会话发送给第三方服务。
- 网易云歌词查询依赖未公开的私有接口，可能要求额外安全验证或因服务端变更而失效；失败时显示可读状态且不阻断蓝牙发送。[第三方 API 的登录/歌词实现示例](https://github.com/HyPlayer/NeteaseCloudMusicAPI)；相关旧实现已归档且有登录拒绝/验证问题记录，不能视作网易官方支持。[已归档实现与验证问题](https://github.com/Binaryify/NeteaseCloudMusicApi/discussions/1569)
- 当前歌词来源只允许网易云。登录后搜索曲目并请求其时间戳歌词；未登录、接口不可用、搜索失败或无同步歌词时显示对应状态，不查询 LRCLIB 或其他来源。
- 按置信度规则校验候选；艺人匹配需要处理常见字形与署名别名，例如 `张惠妹`、`張惠妹`、`aMEI`。仍需歌名/时长总分达到门槛且歌词含时间戳。对用户报告的“张惠妹《掉了》”加入回归覆盖；没有时间戳歌词的候选不能通过。
- 登录失败（账号错误、网易云风险校验、验证要求或网络失败）显示单独状态；无登录时不尝试其他歌词源。应用不要求用户把密码发送到聊天或任何开发者渠道。

### 本轮验收

- 首版单元测试曾覆盖 LRCLIB 搜索和“掉了/张惠妹”候选；后续网易云专用实现改为覆盖 YRC 时间解析、网易云 YRC 优先及无会话不查询的路径，并保留三行歌词窗口和开机自动连接测试。
- 构建 Android 9 可安装 debug APK，并更新两手机蓝牙测试步骤。实际两手机连接和 UNI-V 悬浮层/车机固件行为需在设备上验证；当前 ADB 无已连接设备，因此本机只能完成自动化测试与打包检查。

## 用户确认的网易云专用歌词与操作更新（2026-10-08）

- 网易云是唯一歌词来源。运行端不再创建 LRCLIB 查询，也不读取可能含旧来源内容的歌词缓存；未登录、无网易云匹配或接口受限时返回未匹配/登录状态。
- 手机端登录入口收为状态卡片；密码和短信验证码表单收进高对比弹窗，登录成功后回到紧凑状态。网易云 8821 属于服务端安全校验，应用无法绕过；当前提供密码与短信验证码方式。
- 请求网易云 YRC 逐字数据并解析绝对字/词时间。车机逐字按进度从未唱色向已唱色扫过；网易云只有 LRC 时继续显示句级颜色，不合成虚假逐字时间。
- 车机设置新增歌词滚动转场时长。短按悬浮歌词显示“隐藏歌词/取消”对话框，长按拖动并保留位置。已配对手机列表通过一个设备选择对话框打开，页面只展示记忆中的当前设备。
